# SmartHomeApp - Product Overview

## Product Description

SmartHomeApp is a premium React Native mobile application for discovering, provisioning, and controlling ESP32-based smart home devices. It provides users with a sophisticated interface to manage connected devices via Bluetooth Low Energy (BLE) and MQTT protocols.

## Core Features

### Device Discovery & Provisioning
- **BLE Device Discovery** - Scan and discover ESP32 devices in provisioning mode
- **WiFi Provisioning** - Configure WiFi credentials for new devices over BLE
- **Device Naming** - Friendly naming for easy identification

### Real-Time Control & Monitoring
- **Live Metrics** - Real-time sensor data via MQTT (soil moisture, temperature, humidity, WiFi signal)
- **Device Control** - Toggle LED and relay controls with real-time feedback
- **Device Status** - Online/offline status with visual indicators
- **Live Activity** - Real-time event tracking and device activity log

### Device Management
- **Device Organization** - Organize devices by room with customizable sorting
- **Rename & Reconfigure** - Modify device names and WiFi settings
- **Device Removal** - Remove devices from home
- **Restart & Factory Reset** - Advanced device operations

### Security & Storage
- **Secure Storage** - AsyncStorage for device list persistence
- **Keychain** - Encrypted storage for WiFi passwords
- **Permission Management** - Bundled permission requests during onboarding

### User Experience
- **Premium UI** - Frosted glass cards, soft shadows, premium design language
- **Smooth Animations** - Interactive transitions and visual feedback
- **Dark/Light Theme** - Themable interface with dark mode support
- **Notifications** - Device alerts and system notifications
- **Settings** - App preferences, theme, language, and device settings
- **User Profile** - Home statistics, account management

## Target Users

- Smart home enthusiasts
- Users managing multiple ESP32-based IoT devices
- Homeowners seeking centralized device control
- Premium mobile app users valuing design and UX

## Key Success Metrics

- Successful BLE provisioning of new devices
- Real-time metrics accuracy and latency
- Device control responsiveness
- User retention and engagement with live activity
- App stability and crash-free performance
